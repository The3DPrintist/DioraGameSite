Reporting bugs:

Is it a bug?

Please check to make sure you have the most recent version of Diora.

If a crash happens during non-editor gameplay, please report it.

For custom levels, please check Level Editing (block demos) first if there is unexpected block behavior. Crashes from incorrect setups are possible, especially when using complex engine features. (consider enabling auto save on test)

Otherwise, please let me know on the Playdate Community Squad Discord thread for Diora, (Link available shortly after launch)
