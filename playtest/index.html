How To Playtest:

Install Diora on your Playdate

Download will be provided privately since this page is public.

Play through the intro if needed.

Select a testing track

The list of testing tracks will be provided privately since this page is public.

Play through each level in the track

To open each level, use the console to start a level: !msg startlevel pushintro

Play them in order!

Submit feedback

Submit this form after each level in the track.

Level Playtest Form

The internal level name is the same name used to open the level (e.g. pushintro)
