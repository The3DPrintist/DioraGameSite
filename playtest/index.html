How To Playtest:

Install Diora on your Playdate

Download will be provided in the discord since this page is public.

Please check to make sure you have the most recent version of Diora in the playtest-information channel

Select a testing track

The list of testing tracks will be provided privately since this page is public.

Prioritize testing tracks that have less reactions.

Since Diora is a puzzle game, I would suggest playing only 1-2 tracks, especially if you would like to play Diora after release.

Play through each level in the track

Start a level either by using this console command: !msg startlevel pushintro, or by using the 'load level' menu option on the map, or by finding the level on the map.

Play them in order!

After completing a testing track, react to the testing track list in discord.

Keep in mind, these levels are early and will change.

Submit feedback

Submit the form below after each level in the track.

The internal level name is the same name used to open the level (e.g. pushintro)
